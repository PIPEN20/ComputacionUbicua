# Computación Ubicua

Presentación web de una sola página (`index.html`, sin dependencias que instalar).

- Navegación: flechas del teclado, o tocar el lado izquierdo/derecho de la pantalla en móviles (también deslizar).
- Para publicarla: sube estos archivos a un repositorio de GitHub y activa **Settings → Pages → Deploy from a branch → main / (root)**.
- Las fuentes se cargan desde Google Fonts, por lo que requiere conexión a internet.
